# VoltWise Core

Core domain and business logic for the VoltWise platform.

This module contains shared models, rules, and abstractions used across all services.

## 🧠 Responsibilities

- Domain models (chargers, sessions, users)
- Business rules
- Shared types and schemas
- Event definitions

## 🛠️ Tech Stack

- Go (Golang)

## 📦 Used by

- voltwise-cloud
- voltwise-ocpp
- voltwise-agent

## 🚀 Goal

Provide a consistent and reusable core across the entire ecosystem.
